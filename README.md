# 🔐 Web Application Security Audit

## 📌 Project Overview

This project was completed as part of my Cybersecurity Internship at XQORA Technologies.

The project focused on performing a hands-on, non-destructive web application security audit and documenting the assessment process.

## 🎯 Assessment Areas

- 🔎 Reconnaissance
- 🌐 Application Mapping
- 🔐 HTTPS/TLS Assessment
- 🕵️ HTTP Traffic Inspection
- 🛡️ Security Header Review
- 📝 Input Point Identification
- 📊 Security Documentation

## 🛠️ Tools Used

- Kali Linux
- Burp Suite
- OpenSSL
- cURL
- Firefox
- DNS Utilities

## 📚 What I Learned

Through this project, I gained practical exposure to how a web application security assessment is performed and documented.

It helped me understand the importance of reconnaissance, traffic analysis, security controls, input validation, and security reporting.

## ⚠️ Disclaimer

This repository contains a public portfolio version of the project.

Client-specific information, target details, sensitive findings, and detailed security evidence have intentionally been excluded.
